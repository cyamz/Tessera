Windows 桌面工具箱：十余个内置工具插件涵盖计算、换算、时间、截图、文件、图片与生活健康场景，全部能力以插件形式装载，可扩展、可停用。数据保存在本地，不依赖云端账号。

## 下载

前往 [Releases 最新版](https://github.com/cyamz/Tessera/releases/latest)：

| 系统 | 下载 | 说明 |
|---|---|---|
| Windows 10/11（x64） | `Tessera-版本-windows-x64.zip` | 免安装，解压后运行 `toolbox_host.exe` |

每个版本附 `SHA256SUMS.txt` 校验文件。

## 主要能力

- **工具即插件**：所有功能以插件形式装载，支持停用与收藏；插件包采用 `.scp` 格式并经 ed25519 签名校验，进程级隔离运行。
- **计算与换算**：科学计算器（表达式求值、函数绘图）、单位换算（长度/质量/数据/货币等十余类，含汇率、燃油等可配置行情源）。
- **时间工具**：世界时钟、国家时间、计时与专注模式。
- **截图标注**：区域截图、贴图、标注与取色。
- **文件中心**：多文件夹工作台，内置查看器支持文本、图片、PDF 等常见格式。
- **图片与文本**：图片实验室（格式转换、水印、背景移除）、文本实验室。
- **生活与健康**：心理测评量表、健康计算器、脑力训练小游戏。
- **外观**：明暗跟随系统、多套界面风格、密度可调，中英双语。
